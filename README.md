# pipeline

一份纯流程契约：规定 agent 在开发编程项目时，主代理、执行子代理、审查子代理怎么协作，什么算完成，什么不算。

**没有脚本、没有工具、没有运行时。** 只有一份流程契约、一份术语表，加一份一次性的迁移说明。

## 文件

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 流程契约本身——全部规则都在这里，也是唯一的权威 |
| `GLOSSARY.md` | 术语表。对同一个词的用法冲突时，以它为准——它只管词，不管规则 |
| `MIGRATION.md` | 从前一版（带 `pipeline_tools` 的那版）迁过来的一次性清理清单。**不是契约的一部分** |

## 用起来

把整个目录放进宿主的技能目录——`SKILL.md` 会引用同目录的 `MIGRATION.md` 与 `GLOSSARY.md`，单读它一份会让那两处引用悬空。

**用之前先看 `SKILL.md` 的「硬前提」。** 不满足的话，这个技能不适用——它没有降级模式，也不接受同一个上下文既实现又审查。
